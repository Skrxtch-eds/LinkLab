# LinkLab

LinkLab — локальный сервис для сокращения ссылок и управления переходами. Ссылки объединяются в папки проектов; для каждой ссылки можно задать срок действия и лимит переходов.

## Возможности

- Папки проектов с названием и описанием.
- Короткие адреса для HTTP- и HTTPS-ссылок; код можно задать вручную или сгенерировать.
- Срок действия и максимальное число переходов.
- Пауза, возобновление, изменение и удаление ссылок.
- Счётчик ссылок и переходов, остаток лимита и времени.
- График переходов по папке за последние 30 дней.
- Статистика ссылки: успешные и заблокированные обращения, устройства, браузеры и последние запросы.
- Локальная база SQLite; сервер по умолчанию доступен только на этом компьютере.

## Быстрый запуск

Требуется Python 3.10 или новее. Дополнительные Python-пакеты не нужны.

**Windows:** запустите `start.bat`.

**Windows, macOS или Linux:** в каталоге проекта выполните:

```sh
python server.py
```

Если команда `python` не запускает Python 3, используйте `py -3 server.py` в Windows или `python3 server.py` в macOS/Linux. Откройте [http://localhost:8080](http://localhost:8080). Для остановки вернитесь в терминал и нажмите `Ctrl+C`.

Сервер раздаёт готовую сборку из `static/`, поэтому для обычной работы Node.js не требуется. Параметры сервера:

```sh
python server.py --port 8090
python server.py --db ./data/test.db
python server.py --open
```

`--host` по умолчанию равен `localhost`. Настройка другого адреса может открыть сервис другим устройствам в сети; перед этим прочитайте [правила безопасности](SECURITY.md).

## Разработка

Нужны Python 3.10+, Node.js 20+ и pnpm. Установите зависимости и запустите backend и Vite в двух терминалах:

```sh
pnpm install --frozen-lockfile
python server.py
```

Во втором терминале, из каталога проекта:

```sh
pnpm dev
```

Откройте адрес Vite, который выведет команда. API и короткие ссылки перенаправляются на backend `localhost:8080`.

Проверки и production-сборка:

```sh
pnpm test
python -m unittest -v
pnpm build
```

`pnpm build` обновляет `static/`. Эти файлы нужны для запуска готового сервиса без Node.js, поэтому каталог `static/` включён в репозиторий.

## Данные и резервная копия

База данных по умолчанию — `data/linklab.db`. Она создаётся при первом запуске и исключена из Git. Перед резервным копированием остановите сервер и сохраните каталог `data/`. Подробнее о хранении и ограничениях статистики — в [руководстве пользователя](docs/USER_GUIDE.md).
