# Безопасность

## Режим по умолчанию

LinkLab не содержит учётных записей, входа или авторизации. Сервер по умолчанию слушает только loopback-адреса (`localhost`), поэтому панель доступна с того же компьютера. Короткие ссылки также работают только в пределах доступности этого локального сервера.

Не открывайте порт LinkLab в интернет и не запускайте сервер на общедоступном адресе. Любой, кто получит доступ к панели, сможет просматривать, менять и удалять ссылки и статистику.

## Доступ из локальной сети

Параметр `--host 0.0.0.0` позволяет подключаться к серверу с других устройств сети. Используйте его только в доверенной сети и только если понимаете, что панель не защищена паролем:

```sh
python server.py --host 0.0.0.0
```

Не настраивайте проброс порта на роутере для этого сервиса. Для удалённого доступа сначала добавьте аутентификацию и защищённое соединение.

## Локальные данные

Ссылки и история обращений сохраняются в SQLite-базе `data/linklab.db`. Эта папка исключена из Git. Не отправляйте её в публичный репозиторий и не включайте в общедоступные резервные копии: в базе могут быть личные адреса ссылок и описания.

LinkLab хранит анонимный идентификатор посетителя в cookie, чтобы отличать браузеры в статистике. IP-адреса и геолокация не сохраняются. Источник перехода берётся из заголовка `Referer`, если браузер его передал.
